# 整图模块与大画布

用于完整项目、整页原理图和用户要求“分模块标识、点击模块分析、画布太小”的场景。模块划分是原图上的标注层，不是把原理图拆成重排的卡片或独立简图。

默认实现直接使用 [画布模板](canvas-template.md)，不要只根据下面的规则另写一套 UI。模板固定已确认的外观和交互，本文解释模块识别及电气映射规则。

## 从整图建立模块

保留原图方向、器件位置、位号、端口和跨模块连接。先核对供电、输入输出与器件网络，再按功能圈定区域；不能只按几何距离判断电气关系。每个模块保存：

- 稳定 ID、名称、页号或层级路径。
- 原始坐标系及一个或多个虚线区域；坐标绑定原图，不绑定屏幕像素。
- 涉及的元件、节点、输入输出接口及共享器件归属说明。
- 一两句用途和怎么使用，来源/可信程度，模型状态及待确认项。
- 模块对应的模型 ID、可调参数、结果和探针；无数值模型时也要有可用的说明面板。

同一模块分散在几个位置时可用多个同名区域，不移动原图拼成一个区域。运放等多单元器件按原图表示保留，可以共享模型和电源。多页项目按原页切换，保存页内模块和跨页网络映射；不要为了“完整”强行把全部页面挤进一张小图。

可用 `modules.json` 保存上述数据。示例结构仅表示字段，不规定电路类型或模块数量：

```json
{
  "schema": "schematic-modules-v1",
  "source_page": "sheet-id",
  "coordinate_system": "original XY; define origin and y direction",
  "full_bounds": [0, 0, 1200, 800],
  "modules": [{
    "id": "input-stage",
    "name": "输入调理",
    "bounds": [100, 120, 440, 400],
    "components": ["U2", "R10"],
    "nodes": ["AIN", "FILTER_OUT"],
    "function": "说明实际识别出的用途",
    "usage": "说明输入、输出和用户可做的操作",
    "model": "解析计算 / 实际仿真 / 预计算或插值 / 定性说明",
    "controls": ["input_voltage"],
    "limitations": "缺失条件或模型边界"
  }]
}
```

## 画布行为

- 初始适应完整原图。提供可操作的大画布、缩放按钮或滚轮、拖动平移和“适应整图”；按当前显示空间确定尺寸，不能仍把高分辨率整图锁在很小的固定高度。
- 内联或自动随内容增高的 iframe 不可再依据其 `innerHeight` 增加画布高度，否则模块面板展开会形成高度反馈循环。使用独立于内容高度的尺寸规则，并检查展开面板后的总高度。
- 独立桌面页面按浏览器可视高度布局，顶部标题与工具栏常驻，工作区占用剩余空间。内外层 iframe 都必须限制在视口内，不让内容高度消息撑大外层页面；画图时读取分配给画布容器的实际宽高。
- 整个应用外层不加大边框、圆角或阴影；保留画布、详情面板和状态栏自己的功能边界，避免三层套框。沿用模板的 4 px 页面留白、6 px 工作区 padding/gap；用户说 UI 间距时不移动图中模块。
- 宽屏详情面板与画布上下对齐，使用清晰的边框区分。面板标题与收起按钮固定，正文单独滚动；底部提示合并成有边界的紧凑状态栏。工具栏按操作、缩放、显示选项和模块选择分组，按钮、开关与选择框在同一基线上。
- 原图、虚线区域、探针使用同一坐标变换。原图微小文字可通过缩放阅读；新加模块名和操作控件应保持清晰，紧凑概览可显示编号并配完整名称选择入口。
- 模块标题优先完整显示在边框外，可比所属模块更宽；以边框中点等固定锚点定位，必要时用短引线指明归属。按适应整图时的尺寸为相邻标题预留固定行位，避开所有电路区域；平移或缩放不能重新分配行位、改变名称格式。常见桌面视口核对全名、标题相互重叠、标题遮挡电路及缩放后相对偏移。极窄视图无法安全容纳时才用编号或隐藏图上标题，模块选择控件仍提供全部完整名称。
- 优化 UI 区块间距时，调整工具栏、画布、详情面板和页面边缘的 padding/gap。保留原理图内各功能模块的坐标与间距，不将 UI 留白请求解释成电路重排。
- 点击模块只更新选中状态和分析面板，不自动裁剪原图、不删除其他模块、不重置用户参数。宽屏旁边展开，窄屏下方展开，可收起给原图腾出空间。
- 图上标识可隐藏。模块选择与节点/支路探针若争抢点击，提供明确模式或不冲突的命中区；不能让整块透明覆盖层挡住所有探针。
- 对每个模块给同等可访问的原生按钮或选择控件，不能依赖鼠标悬停。
- 不假设能修改聊天宿主的画布大小。用户要求更大画布时允许生成独立大视图，在可用的浏览器打开；全屏必须检测宿主许可，失败明确提示并保留可用的大视图。独立页面不需要公开发布。

## 面板与计算

模块面板包含短用途、短用法、相关操作和结果。传感器模块展示其真实物理输入，调理模块展示对应电阻/增益/负载，电源模块只有在已建模时才能显示求解结果。不要为未知模块套分压器滑块。

跨模块共用同一参数状态和计算模型；切换仅改变展示。电源电压若是边界设定，写“设定/假设”，不能显示为电源模块求解值。保留整图未建模器件，禁止用零电流填满表格。

保存页、模块、缩放/平移和经校验的输入；恢复后重算。未知节点、饱和、量程越界和无解状态按建模规则处理，过期结果不可伪装成当前条件。

探针按电气网络去重：直接由导线和同名网络标号连接的所有引脚属于同一节点，不将每个引脚分别列为节点，也不因两个独立节点恰好同电压而合并。一个网络仅显示一个代表测点和一个节点选择项，同网引脚列在详情中。GND 保留为电压参考，不放置节点探针；支路中的接地端可显示参考地说明，不作为可选节点。

选中节点用比普通连接点稍大的红色实心圆点及柔和外环，显示精确位号/引脚；其他节点用更小红色空心圆提示，视觉大小与点击命中范围分离。右侧顶部固定显示同一测点的位号、电压、参考地和同网引脚，详情滚动时读数仍可见。支路探针显示带方向的电流及两端电压，同一网络的多个支路引脚合并。按实际引脚归属选模块。

## 验收

对实际电路执行与改动相关的检查：

1. 全图器件与连线仍在；模块覆盖合理，原图坐标和原文件未改。
2. 真正点击区域和标题可展开对应面板，切换保留参数和整图。
3. 改参数影响实际模型；已验证默认值、改值和边界结果未被 UI 改造破坏。
4. 缩放与平移后区域仍对齐，“适应整图”恢复位置；探针模式仍可点击原件/节点。
5. 检查大屏、窄屏、深浅色；若提供全屏，实际验证进入、退出或受限时的回退。
6. 独立页面检查常见桌面视口（如 1366×768、1280×720）：文档无纵向溢出；面板滚到最底部后，顶部工具栏、面板标题与状态栏仍在原位；展开更多参数不能撑高整页。

本项目电路的模型和演示留在工程目录，不把某一份客户原图或固定模块参数打包成通用技能默认值。
