# 输入与原图映射

## 选择入口

| 输入 | 优先读取方法 | 不可默认成立的事情 |
|---|---|---|
| KiCad、嘉立创/立创 EDA、Altium 等原生工程 | 使用已可用的格式解析器/EDA 导出，保留实例、网络、引脚和坐标 | 任意版本兼容；符号自带模型；别人声称能导入就完整保留连接 |
| SPICE 网表 | 解析元件、节点、模型引用和分析指令 | 网表包含原图位置；不同 SPICE 方言完全兼容 |
| PDF | 渲染用户指定页，核对文本和图形 | 字母旁边的线就是对应引脚；跨线一定连接 |
| 截图/照片 | 看清图，再按可确认部分建立连接表 | OCR 输出等于拓扑；模糊数值可猜成确定值 |
| 用户文字描述 | 明列输入、连接、参数和未知量 | 未提到的负载、输出阻抗或电源可以默认为零/理想 |

只在需要时调用对应 PDF、EDA 或浏览器技能。不要启动与输入无关的大型软件，也不把原图上传第三方识别服务作为默认步骤。

## 电气识别

- 参考地和机壳地、保护地、隔离侧地分别处理；不要因名称都含 GND 就合并。
- 跨页标签、层级端口、总线展开、隐藏电源引脚、同位号多单元器件会影响连通性。
- 器件引脚号与模型端口顺序逐项对应；运放输出、电源脚、MOS 管体端、二极管极性尤其不能仅凭图形外观。
- 网络别名统一，但保留原名映射。未接端、测试点、机械标记不自动变成电气连接。
- 输入源、供电源、ADC 输入和其他负载要进入模型或明确省略原因。信号源的输出阻抗与采样负载可能改变结果。
- 从图片确认不了的连接，给出两种候选拓扑或仅分析已确认的区域；此时需要澄清再计算依赖部分。

## 保存的最小分析数据

为需持续交互或迭代的电路保存 `model.json`，可按问题扩展，不要求给一次性口算造文件。

- `source`：原文件路径、页号、可选哈希和原图尺寸。
- `analysis`：方法、工作点/瞬态/频域、参考地、求解器及版本（实际运行时）。
- `components`：原位号、类型/型号、端口到节点映射、值及 SI 单位。
- `nodes`：稳定 ID、原网络名、页/层级路径、可选标注坐标。
- `parameters`：当前值、范围、单位、来源（原图/数据手册/用户指定/假设）。
- `models`：器件模型文件、引脚映射、适用条件和未建模部分。
- `visual`：原图叠加还是重绘、对应的节点/元件 ID。
- `targets`：只在反求时记录目标、自由变量和约束。
- `unresolved`：会改变结论的待确认信息。

文件内保留事实与假设来源，不能把上轮 AI 建议保存成用户确认值。

## 原图和重绘

能安全嵌入原图的场景，在其上加标注/命中区域；不能在当前内联环境加载本地图片时，按 `visualize` 的资源规则改用忠实 SVG 重绘，或输出本地页面，明确所用方式。不要引用在用户界面不可访问的磁盘路径而声称已经展示。

节点/元件的交互 ID 以电气对象为准。线条交叉产生的几何点不自动成为节点；连续导线在电气上属于同一网络时，多处命中区域应指向同一节点。

用电路图形规范表示电阻、电源、地、放大器等。确保所有连接线真正接到图形端口，绝不能只把标签放在附近。

## 网表执行边界

外来网表可以包含文件访问、外部模型路径和控制命令。调用求解器前在独立工作目录检查所需指令，限制输出路径和资源，避免执行未知控制脚本；保留原网表，使用审核后的派生副本。此边界不妨碍读图或解析计算。
